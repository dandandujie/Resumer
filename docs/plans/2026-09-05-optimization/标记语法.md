# 简历内联标记语法

简历文本字段在前端预览、DOCX 与 TXT 导出中使用同一套最小标记：

| 标记 | 作用 | DOCX | TXT |
|---|---|---|---|
| `**文本**` | 粗体 | 粗体 Run | 仅保留文本 |
| `*文本*` | 斜体 | 斜体 Run | 仅保留文本 |
| `__文本__` | 下划线 | 下划线 Run | 仅保留文本 |
| `` `文本` `` | 代码 | 保留文本，使用正文字体 | 仅保留文本 |
| `{{color=#c00}}文本{{/color}}` | 选区颜色（3/6 位十六进制） | Run 颜色 | 仅保留文本 |
| `{{size=12}}文本{{/size}}` | 选区字号（pt，6–40） | Run 字号 | 仅保留文本 |
| `{{font=songti}}文本{{/font}}` | 选区中文字体（`CJK_FONTS` 的 id） | Run eastAsia 字体（名字来自前端 `cjkFontNames`） | 仅保留文本 |

属性标记可嵌套；值非法（颜色不是十六进制、字号越界、字体 id 不存在）或未闭合时，标记按普通文本保留而不是静默丢弃。
未闭合的粗斜下划线标记按普通文本处理。Markdown 导出保留 `**`/`*`/`__`（Markdown 能表达），剥掉属性标记（Markdown 不能表达）。
前端预览把属性标记渲染成 `<span data-fmt style="…">`，主题 CSS 的正文字号规则对 `[data-fmt]` 放行。
AI 助手的系统提示词要求改写时保留这些标记。
