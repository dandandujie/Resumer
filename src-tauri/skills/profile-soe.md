# 岗位画像：国企 / 央企 / 事业单位

> 国有企业、央企、事业单位、公务员体系（含国企市场化岗位）的简历定向优化知识。

## 筛选逻辑与体制内偏好
- 初筛高度形式化：学历学位全称、院校层级、专业与岗位要求的**精确匹配**（专业名称差一个字都可能被卡）、政治面貌、年龄线（很多岗位 35 岁硬线，管培 28 岁内）。
- 「稳定性」是核心叙事：频繁跳槽在体制内简历中是重大减分项，必须弱化（合并短经历，突出长期主义动机）。
- 措辞风格：稳重、规范、集体导向。互联网风格的「增长黑客」话术要全部转译成体制内语言（如「牵头」「统筹」「落实」「攻坚」）。

## 必写字段（与市场化简历相反）
- 政治面貌（中共党员/预备党员是显著加分项，置于个人信息区）。
- 学历学位分开写全称：「XX大学 工学学士 / XX大学 管理学硕士」，标注全日制与否。
- 荣誉奖项前置：奖学金（国家/省级）、三好学生、优秀学生干部、优秀共产党员/团员。
- 学生干部与党团经历：班长/团支书/学生会职务在这里是硬通货，写明规模与组织的活动。
- 通常需要标准证件照；籍贯、出生年月按招录公告要求补全。

## 经历写法
- 集体与个人平衡：「作为项目组核心成员，牵头完成XX」比纯个人英雄叙事更受欢迎。
- 体现「政治素养 + 执行力」：参与的党建活动、志愿服务、重大保障任务（进博会/运动会志愿者等）都值得写。
- 量化仍然有效但口径不同：服务人次、覆盖单位数、材料/制度产出、获得的上级批示或表彰。
- 文字功底是隐性核心能力：写过的公文、调研报告、宣传稿数量与被采用情况。

## 分类型侧重
- **央企总部/管培**：院校层级+党员+学生干部三件套；外语（四六级分数写出来）；海外经历是加分项。
- **地方国企**：本地关联度（生源地、意愿稳定性）；相关行业实习。
- **事业单位/高校行政**：公文写作、活动组织、耐心细致的佐证。
- **国企市场化岗位**（科技子公司等）：介于两者之间——专业能力为主，但党员和稳定性仍加分。

## 红线
- 政治面貌、学历性质（全日制/非全）绝不可模糊或造假，政审环节全部核实。
- 避免出现价值观风险表述（拜金、躺平、频繁跳槽动机）。
- 不要用花哨模板：黑白灰规范排版，无大面积色块。
