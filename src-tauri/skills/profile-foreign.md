# 岗位画像：外企

> 欧美/日韩外资企业（快消、医药、制造、科技、专业服务）的简历定向优化知识。

## 筛选逻辑
- 多数外企用全球化 ATS（Workday、SuccessFactors、Taleo），**英文关键词命中**决定简历能否进入人筛，中文简历投外企岗位常直接被系统忽略。
- 建议配置：中英双语两版简历；英文版为主投递版本。
- 英语能力是隐性硬门槛：简历本身的英文质量就是第一轮英语笔试。

## 英文简历规范（与中文简历差异点）
- 不放照片、年龄、婚育、政治面貌（合规文化，放了反而显得不专业）。
- Bullet 以过去式强动词开头：Led / Drove / Built / Launched / Reduced / Streamlined；在职经历用现在时。
- 删除所有第一人称（I/My）；每条 bullet 一行到两行，量化结果放句尾或句首强调位。
- 常见 Chinglish 纠正：
  - 「负责」≠ be responsible for（弱），用 owned / managed / oversaw
  - 「配合」≠ cooperate with（生硬），用 partnered with / collaborated with
  - 职务标准化：学生会主席 → President of Student Union；三好学生 → Merit Student Award
- 教育：GPA 用 x.x/4.0 格式；交换经历、英语成绩（IELTS/TOEFL/CET-6 高分）写出来。

## 内容偏好
- 结果导向 + 软技能佐证：外企面试围绕 competency（leadership、stakeholder management、problem solving），简历 bullet 要为这些故事埋点。
- 跨文化协作经历权重高：与海外团队/总部协作、英语工作环境、跨时区项目。
- 快消（宝洁/联合利华系）：管培笔面看重领导力故事，简历中社团/项目的 ownership 叙事要完整（背景-行动-结果）。
- 医药外企：合规敏感，学术推广经历措辞规范；证书（执业药师等）与产品线经验写清。
- 外资科技/专业服务：认证（PMP、AWS/Azure、CFA）与全球方法论（Agile、Six Sigma）术语原文保留。

## 红线
- 英文简历中的语法错误是致命伤（一处拼写错误足以出局），生成后必须过一遍语法检查。
- 不要直译中文成语和口号式表达。
- LinkedIn 资料与简历一致性：外企 HR 习惯交叉核对。
