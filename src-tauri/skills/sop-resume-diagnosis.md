# SOP：简历诊断流程

> 用户要求"看看我的简历"/"帮我优化"且未指定具体模块时，按此流程执行诊断。

## 第 0 步：补齐定向信息
缺以下任一信息时先问（一次问完，不要挤牙膏）：
1. 目标岗位与行业（有 JD 最好）
2. 工作年限与当前职级
3. 投递方向：大厂互联网 / 国企央企 / 外企 / 中小公司（决定简历风格基调）

拿到岗位方向后，先 readSkill 对应的岗位画像技能再开始诊断。

## 第 1 步：硬伤扫描（模拟 6 秒初筛）
按 HR 视线路径快速过一遍，输出「致命问题清单」（最多 3 条，按杀伤力排序）：
- [ ] 基本信息完整性（联系方式、意向岗位）
- [ ] 时间线：断档 > 6 个月？3 年内跳槽 > 2 次？时间格式统一 YYYY.MM？
- [ ] 篇幅：应届/3 年内超过 1 页？资深超过 2 页？
- [ ] 模块顺序是否符合画像（校招教育前置，社招经历前置）
- [ ] 有无照片/年龄等与投递方向不符的信息

## 第 2 步：内容质量逐条评估
对每条工作/项目经历打标：
- 【无结果】只有职责没有结果 → 最高优先级改写
- 【无量化】有结果没数字 → 追问用户真实数据或标【建议补充】
- 【弱动词】"负责/参与"开头 → 换强动词
- 【自评词】"学习能力强"类 → 删除或转事实
- 【关键词缺失】对照目标 JD/岗位画像的核心词 → 自然融入

## 第 3 步：输出与执行
1. 先给诊断总结：致命问题 + 3 个最值得改的点（说明对应哪条筛选逻辑）。
2. 征得同意后用工具逐模块改写；每次改动说明理由。
3. 全部完成后给「用户待办清单」：需要用户本人补充的真实数据（量化占位处）、需要线下准备的事项。

## 禁止事项
- 不要一上来就全量改写（用户失去控制感）；诊断 → 确认 → 执行。
- 不要编造任何数字；不要删除用户的模块。
