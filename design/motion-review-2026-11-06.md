# 动效细化验收记录 · 2026-11-06

用户要求：全项目使用更灵动，动效赏心悦目、恰到好处、流畅自然。本轮沿用 v2，统一共享组件节奏，不更换颜色、字体或布局方向。

## 实现

- 共享时长：按下 80ms、状态变化 120ms、进入 160ms；统一减速曲线。
- 页面、Wiki、标签内容和助手展开使用淡入；小弹层 3px 进入，替代抽屉原有 500ms 整屏滑入。内容无需等待动画才可操作。
- 按钮 1px 按下反馈；导航、选择器、输入、开关、投递列表统一状态过渡。
- Tooltip 停留 300ms 后出现，避免掠过工具栏连续闪烁。
- 弹层关闭不等待退场动画；避免 WebKit 漏发 animationend 留下遮罩。
- 减少动态效果直接关闭 CSS 动画/过渡，修正无限动画被压到 .01ms 反而加速的问题；Framer Motion 采用系统偏好。
- 路由切换后若焦点因原控件卸载而落到 body，聚焦带当前任务名称的 main；保留已有输入/恢复焦点。
- Dialog 记录实际打开入口，关闭后返回仍存在的入口，尊重调用方的自定义焦点处理。

## 实际操作 → 问题 → 修复 → 复验

computer-use 子代理在隔离 mock 服务 http://127.0.0.1:5186 操作，不访问用户真实资料库。

发现：新建基础简历弹窗 Esc 关闭后焦点落到网页根节点。原因是全局 modal store 控制的 Dialog 没有 Radix Trigger，默认无法找到入口。共享 Dialog 增加实际入口记录与返回后，子代理再次操作确认焦点返回“新建基础简历”。

实际已验：默认窗口浅色首页→求职→知识库切换，知识库空资料集引导；新建弹窗居中、输入获焦、Esc 返回；更多菜单贴近入口、方向键聚焦重命名、Esc 返回更多；设置切深色、返回首页、焦点回侧栏设置。一次设置操作超时，重试后成功，没有据此认定原生问题已解决。

补充实际已验：深色示例编辑器的更多菜单、方向键、Esc 焦点返回、排版侧栏与返回首页，未见明显遮挡。发现返回首页焦点落到根节点后，补上工作区路由焦点承接，再次实测确认焦点落在“我的简历”任务区，Tab 继续进入“导入文件”。
